# Obstacle-Avoidance-Smart-Car
This is a repo for an obstacle avoidance car which uses the elegoo robot smart car v4.0.

You have permission to review, edit, and use this code for any project as long as if you publish a project you credit it.

Basically, as the car advances forward, uses the supersonic sensor to scan and measure the distance and if it's close it will turn left in it's place then continue it's direction.
